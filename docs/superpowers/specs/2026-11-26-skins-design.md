# 皮肤和动效

## 为什么

想让客户端更好看、更好玩：换一套配色之外，界面要有常驻的氛围动效，几个关键时刻（发消息、agent 干完了、等你回答）有小表演。网页和 Mac 应用都要有。

样稿：预览页（Artifact「皮肤动效预览」），六套皮肤都在里面跑过一遍，本文的动效描述以它为准。

## 目标

- 设置里选皮肤：苔绿（现在的样子）、樱花、旷野、深海、星夜、像素。
- 每套皮肤 = 配色 + 氛围动效（只在聊天区）+ 事件动效 + 侧栏状态图标的样子。
- 动效开关三档：完整 / 只在事件时 / 关闭。系统开了「减少动态效果」且没手动选过时默认「关闭」。
- 点聊天区空白处有小彩蛋（每套各一个）。
- 自定义贴图：飘落物、干完了飞出的东西、等你回答的标记，可换成自己的图片。
- 网页和 Mac 应用都有；深色皮肤下 Mac 的毛玻璃侧栏跟着变深。

## 不做 / 反目标

- 不仿任何现成游戏或作品的名字、角色、标志、美术和音效。「旷野」只用通用的冒险题材元素（远山、古塔、宝箱、小精灵、符文），图形全部自己画。
- 不加音效。
- 不把用户的贴图写进仓库或安装包，只存在浏览器里。
- 动效不能挡操作（画布都 `pointer-events: none`），不能拖慢列表和聊天（后台标签页暂停；没东西要画时停掉动画循环）。
- 不改协议、不改 server 交互。

## 方案选择

| 方案 | 取舍 | 结论 |
|------|------|------|
| A. Canvas 画粒子和场景，CSS 管配色和状态图标 | 和预览页同一套写法；草地、远山、粒子都好画；一个循环画完，性能可控。要先把写死的颜色收进变量 | **选这个** |
| B. 全部 DOM + CSS 动画 | 不用画布，但几十个粒子都是节点，场景难画、更费 | 不选 |
| C. 引入 tsParticles / Lottie | 省掉粒子系统，但违背「不加依赖」，也帮不上「跟着会话状态演」 | 不选 |

## 设计

### 模块

- `web/skins.js`（纯逻辑，有单测）：六套皮肤的定义（名字、色块、各时段的配色变量、是否深色）、读写设置
  （`happy.skin` = `{ v: 1, id, motion }`）、`timeOfDay(date)`（6–17 白天、17–19 黄昏、其余夜里）、`paletteFor(skin, time)`。
- `web/effects.js`（只在浏览器里用）：`createEffects(...)` 管两块画布和动画循环。
  - 氛围画布：`main` 的第一个子元素，`z-index: -1`，`main` 加 `isolation: isolate`，画在聊天区背景之上、内容之下。
  - 事件画布：`position: fixed` 铺满窗口，在最上层，画事件动效、彩蛋、等你回答时绕着那一行飞的小精灵。
  - 对外接口：`setSkin(skin, motion)`、`send(el)`、`done(rowEl)`、`click(x, y)`、`setStickers(...)`。
  - `document.hidden` 时不画；氛围关了、也没有事件粒子和等待中的行时停掉 `requestAnimationFrame`。
- `app.js`：把皮肤配色写到 `body` 的行内样式（这样能盖过 `body.desktop-mac` 里的变量），切换 `body[data-skin]` / `[data-time]` / `.dark`；
  在发消息成功、工作状态从「在思考」变成「不在思考」时调用 effects；设置页加「皮肤」「动效」两栏。

### 颜色变量

`index.html` 里写死的颜色收成变量，默认值等于现在的颜色，苔绿皮肤看起来一点不变：
`--surface`（白色的输入框 / 菜单 / 选项）、`--ink-rgb`（各种 `rgba(38,42,39,x)` 的悬停底色）、`--head` / `--head-hover`（电脑卡片的标题条）、
`--amber`（等你回答）、`--code-bg`、`--accent-hover`、`--on-accent`、`--idle`、`--faint`、`--add` / `--del`、`--danger-tint`。
Mac 一节里的白色卡片、按钮、毛玻璃底色改成用 `color-mix` 从 `--surface` / `--sheet` 派生。
深色皮肤再补上代码高亮（highlight.js 的 github 主题是浅色的）和 markdown 表格、行内代码的深色值。

### 事件

- 发消息：`send()` 成功后，从发送键出发。
- 干完了：`trackActivity` 和 `onEphemeral` 里 `isThinking` 从真变假、且不在等你回答时，在侧栏那一行演；那一行看不见（手机上在聊天里、分组折叠）而它是当前会话时，改在发送键附近演。同一个会话 3 秒内只演一次。
- 等你回答：侧栏 `.row.asking` 的状态图标按皮肤变（CSS）；旷野另有小精灵绕着那一行飞（事件画布每帧画）。
- 工作中：侧栏状态图标按皮肤变（CSS，隐藏原来的 svg，用伪元素画）；旷野在「正在思考」后面加依次亮起的符文。

### Mac 应用

- 新桥接接口 `setAppearance(dark)`：主进程设 `nativeTheme.themeSource = dark ? 'dark' : 'light'`，毛玻璃跟着变深。
  按 desktop/AGENTS.md 的四处改（preload、main 的 `bridge()`、`web/desktop.js`、`smoke.js`）。
- 毛玻璃侧栏的 `--glass` 等变量由深色配色覆盖。

### 自定义贴图

- 三个位置：`fall`、`done`、`ask`。图片缩到最长边 128px 的 PNG data URL，存 `happy.skin.sticker.<位置>`，每张限 200 KB。
- 设了 `fall` 时替换皮肤自己的小飘落物（花瓣 / 叶子……），场景（远山、草地）照旧；`done` 在原有动效之外多飞出几个；`ask` 替换小精灵，其他皮肤上也显示。

## 分两步

1. 皮肤框架、颜色变量、设置里的「皮肤」「动效」、Mac 的深浅色桥接；苔绿、樱花、旷野三套（旷野含白天 / 黄昏 / 夜里）。
2. 深海、星夜、像素，自定义贴图。
