# 靶场皮肤

日期：2026-11-27。预览页：https://claude.ai/artifact/VNQNLd7dum8RyuuavHdckG（用户看过后说「ok」）。

## 为什么

用户想要一套带 FPS 元素的皮肤，要求「需要带一些 fps 要素」：不只是配色，要有准星、武器、弹药这些一看就是射击游戏的东西。
沿用现有的皮肤框架（`skins.js` 配色、`effects.js` 动效、侧栏状态图标、动效三档、Mac 深色桥），做第 7 套。

## 要什么

- 固定深色：深炭灰底，HUD 主色亮橙，完成用青绿，等你回答 / 受击用红。
- 每个游戏元素对应 Happy 里一件真实的事：

| 元素 | 对应 | 在哪一层 |
|------|------|----------|
| 准星 | 聊天区中央，发消息 / 点空白时散开再收回 | 氛围 |
| 手持武器 | 右下角原创科幻发射器；发消息 = 开火：后坐、枪口火光、曳光、抛壳；打空 30 发自动装填 | 氛围（火光、弹壳在事件层） |
| 弹匣 | 每发一条消息少一发，备弹 ∞ | 氛围 HUD |
| 雷达 | 侧栏会话：橙色工作中、红色闪烁等你回答、灰色其余 | 氛围 HUD |
| 「连接」血条 | 实时连接：断线时掉到低位显示「重连中」，发送失败掉一截再回满 | 氛围 HUD |
| 战报 | 会话干完了，右上角滑出「Claude ✓ 会话名 完成」；5 秒内连续完成显示「连续完成 ×N」 | 事件 |
| 命中标记 | 点聊天区空白：命中标记 + 火星 + 很快消失的弹痕；干完了：中央大命中标记 + 「+100」 | 事件 |
| 靶子 | 地平线上横移的圆靶，每干完一个打倒一个 | 氛围 |
| 锁定框 | 等你回答的那一行，四个红角收拢 | 事件层（同旷野的小精灵） |
| 受击 | 发送失败：屏幕边缘泛红、准星旁一道受击弧 | 事件 |

- 侧栏状态图标：工作中是转动的准星，等你回答是闪烁的「[!]」。空闲图标不换（和别的皮肤一致）。
- 设置里多一个「手持武器」开关，只在选了靶场时出现，存在 `happy.skin` 的 `gun`（默认开）。

## 不要什么

- 不出现真实枪械型号、血、击杀字样，不用任何具体游戏的名字、界面或图标。
- 不把鼠标换成准星（影响选字），准星不跟鼠标走。
- 不震屏（预览页里有，进 app 去掉：对晕动敏感的人不友好，和受击泛红重复）。

## 做法

- 靶场的场景、HUD、武器和专属粒子放新文件 `web/range.js`，`effects.js` 只做分发，避免它继续膨胀。
  纯函数（弹匣、连续完成计数、雷达点位、HUD 可用区域）单独导出，`node --test` 覆盖。
- 「只在事件时」：没有氛围层，所以没有枪和 HUD；发消息改成发送键上的火光 + 弹壳，其余事件照常。「关闭」什么都不画。
- HUD 避开聊天头部、输入框和停靠的链接面板；设置页、用量页里不画 HUD 和枪（只留背景）。
- 画布字体只用系统等宽字体，不引网络字体。
- app.js 新增：`effects.hurt()`（发送失败）、`effects.setOnline(bool)`（socket 连上 / 断开）、`effects.done(el, name)` 多传会话名；
  `effects.setSkin(id, motion, time, { gun })`。

## 留给实现时定

- 枪、HUD 的具体尺寸随聊天区大小缩放，窄窗口（< 520px 宽）不画枪，只留 HUD。
- 雷达最多 12 个点：先工作中和等你回答的，再补其余。
