# happy-web-mini · web

在浏览器里用的最小 Happy 客户端：看电脑上 Claude Code / Codex / Cursor / Gemini 会话的进展，回复、批准、回答提问，
新建和归档会话。直连官方 server（`https://api.cluster-fluster.com`），消息在浏览器里端到端解密。无构建步骤。

开发规范和实现要点见 [AGENTS.md](AGENTS.md)。

## 快速开始

```bash
npm install
npm start            # 写 build-info.json（设置 › 关于 里显示的提交号），再起 python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
# 在远程机器上跑：ssh -L 8080:localhost:8080 <host>，再在本机打开 localhost:8080
```

登录有两种方式：用手机上的 Happy App 扫码（App › 关联新设备），或者粘贴备份密钥。

http 下也能用（加解密是纯 JS 实现），但页面可能被中间人篡改，能用 https 或 ssh 转发就别用裸 http。

## 会话列表

- 只显示在线的会话（15 分钟内有活动、没归档），按电脑分组。每台电脑下面分「Bot」（Happy Agent 的 bot）、
  「任务」（`~/Tasks/…`）和普通会话；普通会话按 项目目录 › worktree › 会话 排成树，`.dev/worktree/*` 归到所属仓库下。
  分组和排序跟官方 App 一致，心跳不会打乱顺序。
- 每行最前面是 agent 的图标（Claude / Codex / Cursor / Gemini，悬停看名字），然后是状态：
  转圈 = 正在工作（含后台任务还在跑）、琥珀色 = 等你批准或回答、绿色实心点加粗 = 完成了但你还没看。
- 每行最右边是这个会话改了多少行代码，如「+120 −34」，悬停看改了几个文件（见下面的[改动行数](#改动行数)）。
- 电脑、项目、worktree 都能折叠；折起来时里面有要你处理或未读的会话，标题后面亮个点。
- 列表最下面是「已归档」（默认收起）：按归档时间从新到旧，每次显示 30 个，「再显示」继续。
- 右键菜单：会话上可以打开、标为已读 / 未读、在这个项目新建会话、复制目录或会话 ID、归档；
  电脑上可以新建会话、全部标为已读、收起 / 展开；项目和 worktree 上可以新建会话、复制路径。↑↓ 选，回车执行，Esc 关。
- 侧栏宽度拖右边缘调（双击恢复默认），⌘/Ctrl + B 收起侧栏。
- 打开页面时自动打开第一个未读的会话，没有未读就打开列表第一个。打开即已读。

## 聊天

- 新消息实时推送，断线时自动轮询，重连后补齐。打开会话先取最新 100 条，往上滚再加载更早的，位置不跳；
  切回打开过的会话直接显示，回到上次的滚动位置。
- agent 的回复按 Markdown 渲染，代码块高亮。代码块右上角、回复下方有复制按钮（每轮的最终回答上常驻）。
- 一轮里的中间过程和工具调用收在「已工作 7分2秒 · 14:35」下面，最终回答留在外面；进行中显示「正在工作 12秒」实时走秒。
  工具调用显示成一行（图标 + 命令 / 文件 / 搜索词），点开看完整参数。
- 你发的消息下面显示发送时间；今天的只显示时分，更早的显示「昨天」「11月5日」等。
- agent 消息末尾的 `<options>` 显示成按钮，点一下就作为下一条消息发出去，不影响输入框里的草稿。
- 后台任务：一轮结束后还在跑的后台 subagent / 命令，在对话末尾显示「后台运行中：A 等 2 个」，点开看每个跑了多久，
  点某一个跳到启动它的地方。CLI 有时收不到任务结束的信号，所以每条后面有 × 可以手动清掉。
- `/clear`、压缩、中止这类 CLI 状态显示成灰色提示行。`/clear` 只清 agent 的上下文，聊天记录还在。

## 发消息

- 输入框下方选模型、思考强度和权限模式，按会话记住；没选时按设置里的默认值发（输入框显示「默认：…」）。
  - Codex 的模型列表实时从那台电脑上的 Codex CLI 查，跟 CLI 的模型菜单一致（包括自定义 provider）；
    最前面的「跟随 Codex 配置」表示用那台电脑 `~/.codex/config.toml` 里的设置，要在会话第一条消息（或 `/clear` 之后）就选上才生效。
  - Cursor 的模型和强度来自 Cursor 会话上报的列表。
  - 权限模式：Claude 有 默认 / 自动接受编辑 / 计划模式 / YOLO；Codex 有 自动 / 谨慎 / 只读 / 工作区放行 / YOLO；
    Cursor 有 Agent / 计划模式 / 只问答 / YOLO；Gemini 有 默认 / 只读 / 工作区放行 / YOLO。
    批准 Claude 的计划后自动切回「默认」。Claude 不能从 YOLO 直接降回「默认」，要先选「自动接受编辑」或「计划模式」。
- 发图片：点「图片」、粘贴或拖进输入框，一次最多 10 张，大图自动压缩。只发图片时自动补一句「请看这张图片。」。
- 打 `/` 联想斜杠命令和 skill，↑↓ 选，回车或 Tab 补全。
- 输入框为空时按 ↑ 翻出这个会话里之前发过的消息（手机上发的也算），↓ 往回翻。
- 每个会话的草稿分开保存。
- 输入框下方还显示：上下文还剩多少（剩 ≤25% 变琥珀色，≤10% 变红），Claude 会话的订阅用量
  「5 小时 42% · 7 天 18%」（≥90% 琥珀色，用尽变红，悬停看重置时间）。

## 批准和回答

- 工具审批：agent 要跑权限模式之外的命令、改文件、调 MCP 工具，或者提交计划时，输入框上方出现审批卡片，
  写明要做什么、在哪个目录，可以展开看完整参数。「允许 / 拒绝」；Codex 和 Cursor 会话还能「本会话都允许」。
- 回答提问：Claude 的 AskUserQuestion 和 Codex / Happy Agent 的表单显示成卡片，支持单选、多选、自己填和「不回答」。
- 等你处理的会话在列表里标「等你批准」「等你回答」，算进通知和角标。

## 新建、归档、恢复

- 新建会话（左下角）：选电脑、填目录（下面列出这台电脑用过的项目）、选 agent（只列这台电脑装了的）。
  目录不存在会先问要不要创建。可以顺手新建一个 worktree（`.dev/worktree/<随机名>`），或选这个仓库已有的 worktree。
  启动后自动打开新会话；daemon 等不到 CLI 启动时给出原因，建议重试。
- 归档：结束 CLI 进程并标记为已归档；电脑离线时只改标记。归档的是某个 worktree 里最后一个在线会话时，
  可以勾选同时删掉这个 worktree（有未提交的改动会再确认一次；分支没合并就保留）。归档后自动打开相邻的会话。
- 恢复：已归档或离线的会话底部有「恢复会话」（右键菜单里也有），在原来的会话上接着跑，历史都在。
  电脑不在线、Happy 版本太旧等原因不能恢复时，按钮置灰并说明原因。

## 右栏链接

会话里你和 agent 提到过的链接，按 MR / PR（Codebase、GitLab、GitHub）、飞书文档、Meego、Bits、其他 分组列在右栏。
工具调用和输出里的链接不算。同一个链接只列一次，标「提到 N 次」；点名字打开，点下面的「你 / agent · 时间」跳回原文。
打开会话后会在后台把更早的历史也扫一遍，结果存在本浏览器。窗口够宽时常驻右边，可以收起；窄屏从标题栏的链接按钮打开。

## 改动行数

会话列表每行最右边、聊天标题下面显示这个会话改了多少行代码：绿色是新增，红色是删除，没改过文件就不显示。

- 按会话里改文件的工具调用算：Claude 的 Edit / MultiEdit 逐行比较改前改后，Write 写入的内容都算新增；
  Codex 数补丁里的增删行；Cursor 看工具参数里的 diff；subagent 的改动也算。
- 统计不到的：在命令行里改的（sed、脚本等）；Write 覆盖已有文件时被覆盖掉的旧内容；被拒绝或执行失败的修改也会算进去。
- 打开页面后在后台逐个统计所有在线会话（正在看的优先），数字会陆续出现；之后新消息到了直接累加。
  结果存在本浏览器，下次只补新的。已归档的会话显示以前统计过的数字，打开时再补齐。

## 设置

侧栏顶部「设置」：

- 每种 agent 的默认模型、强度和权限模式。
- 左上角显示的名字（同时是标签页标题），留空恢复成 Happy。
- 背景：几种预设颜色、自定义颜色，或者自己的图片（铺满整个窗口，「淡化」调深浅）。
- 字号：90% 到 140% 几档，只影响聊天区的消息和输入框。
- 通知：会话完成或开始等你回答、而这个标签页不在前台时发系统通知，点通知打开那个会话。需要 https 或 localhost。
- 关于：版本号和提交号（`npm start` 那一刻的代码，带「含未提交的改动」表示当时工作区有改动）。
- 退出登录。

标签页标题会带上需要你处理的会话数，如「(2) Happy」（完成未读 + 等你回答）。

这些设置，连同已读记录、折叠状态和各种缓存，都只保存在这个浏览器里，换个浏览器要重新设置。

## 不做什么

逐字流式输出（协议里没有增量）、非图片附件、旧版 secretbox 加密的会话。

## 安全

账户主密钥存在 `localStorage`，任何能在这个 origin 跑 JS 的东西都能读到它。只在自己信任的机器和域名上用。
退出登录会清掉密钥和从会话里解密出来的缓存。

## Mac 应用

[`../desktop/`](../desktop/README.md) 把这个页面打包成 macOS 应用，功能一样，另外有菜单、Dock 角标和系统通知。
网页改了之后，Mac 应用要发新版本才会更新（见 [../AGENTS.md](../AGENTS.md) 的「发版」）。

## 文件

- `index.html` — 页面结构和全部样式
- `app.js` — 登录、会话列表、消息收发、实时推送、归档和恢复，把下面各模块接到界面上
- `crypto.js` — 密钥派生、数据密钥解包、AES-GCM、备份密钥解析，对照 happy-ios 的测试向量验证过
- `models.js` — 每种 agent 可选的模型和强度；Codex 优先用 CLI 的实际列表，其余对照 iOS 的 ModelModeOptions / AgentDefaults
- `codexModels.js` — 经会话的 `bash` RPC 查询 Codex 配置和模型列表，按会话缓存，失败后重试
- `defaults.js` — 默认模型 / 强度 / 权限的存取，以及对某个会话是否适用
- `permissions.js` — 每种 agent 的权限模式
- `questions.js` — 找出待回答的问题，组装回答和拒绝的 RPC，对照 iOS 的 AgentCommunications
- `approvals.js` — 工具审批卡片：要做什么、文案、允许 / 拒绝的 RPC
- `options.js` — 解析助手消息末尾的 `<options>`
- `commands.js` — 斜杠命令列表、搜索、光标处 `/词` 的识别和替换，对照 iOS 的 ComposerAutocomplete
- `history.js` — 输入框 ↑↓ 翻历史消息
- `localCommand.js` — 把 Claude Agent SDK 包装过的斜杠命令消息还原成可读的样子，对照 iOS 的 LocalCommandMessage
- `tools.js` — 每种工具的图标、一行摘要和详情，时长格式；图标用 Lucide（按需引入）
- `agentIcons.js` — Claude / Codex / Cursor / Gemini 的 logo
- `markdown.js` — Markdown 渲染、代码高亮和 HTML 过滤
- `clipboard.js` — 复制按钮
- `contextmenu.js` — 侧栏右键菜单
- `attachments.js` — 图片压缩、加密上传、下载解密，对照 iOS 的 HappyAPI+Attachments / BlobCipher
- `serverUrl.js` — 自托管服务器返回 http 地址时改写成 https
- `background.js` — 「后台运行中」的任务：启动、结束、手动清除
- `usage.js` — 订阅用量的排序、文案和提示，对照 iOS 的 SessionComposerRules.usageLimitRows
- `context.js` — 上下文剩余
- `links.js` — 右栏链接：提取、分类、去重，分页扫描历史和本地缓存的区间衔接
- `lines.js` — 改动行数：从改文件的工具调用算增删行，按会话累计，从服务器补齐历史
- `resume.js` — 恢复会话：能不能恢复、为什么不能，对照 iOS 的 SessionDetails / MachineActions
- `worktree.js` — worktree 的列出、新建、删除（经 daemon 的 `bash` RPC）
- `desktop.js` — 需要你处理的会话数（Mac 的 Dock 角标、浏览器的标签页标题）和系统通知，网页和 Mac 应用共用
- `wallpaper.js` — 背景颜色和图片
- `fontscale.js` — 字号档位
- `time.js` — 消息时间的格式
- `viewport.js` — 手机上弹出键盘时让页面跟着可视区域缩放
- `version.js`、`build-info.mjs` — 设置 › 关于 里的版本号和提交号
- `test/` — 单测，`npm test`
