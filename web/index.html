设置

名称

左上角和浏览器标签页上显示的名字，留空就是 Happy。只保存在这个浏览器里。

通知

只在这个标签页不在前台时通知，点通知直接打开那个会话。只对这个浏览器生效，页面要开着。

默认模型和权限

给会话发消息时，如果没在输入框下方单独选过，就用这里的默认值。只保存在这个浏览器里，不影响手机 App。Happy Agent 会话用它自己的模型和权限，不受影响。 权限不指定时由 Happy CLI 决定（Codex 是「自动」）。Claude 会话进了 YOLO 之后，CLI 不接受直接降回「默认」，要降级请选「自动接受编辑」或「计划模式」。
